# infra/apps/web — taskflow-app (dev, compute: Azure Container Apps)

Generated by slipway from `templates/compute/aca/per-app/infra/apps`. Owns exactly one container app, `web`, in the shared
environment `cae-taskflow-app-dev` (created by `infra/foundation`), pulling `acrtaskflowdev.azurecr.io/taskflow-app/web:<image_tag>` with the identity `id-taskflow-app-dev`.
Other apps have their own root module and state, so deploying `web` never plans another app's image.

| Command | Who |
|---|---|
| `/slipway:plan dev --layer apps/web --image-tag <tag>` | anyone; read-only |
| `/slipway:deploy web <tag> dev` | triggers `taskflow-app-web-cd`: plan job, then apply behind the `dev` environment approval |

Never apply this layer from a laptop: the guard hook blocks it and the state key (`taskflow-app/apps/web/dev.tfstate`) is written by the CD identity.
